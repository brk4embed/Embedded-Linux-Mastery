# 11 — KPI Tracking

> Update this file every Sunday. 15 minutes of honest review beats 10 hours of untracked effort.

## How to Use This File

1. Copy the **Weekly Entry Template** at the bottom of this file
2. Paste it above the previous entry (newest at top)
3. Fill it in every Sunday evening
4. Review the **Trend** column monthly to see where you're stalling
